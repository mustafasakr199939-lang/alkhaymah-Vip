# منتجع الخيمة VIP

تطبيق ويب عربي RTL لواجهة منتجع الخيمة، يتكوّن من صفحة تسجيل/عضوية وحجز (`index.html`) ولوحة تجريبية لإدارة بطاقات الولاء (`wallet.html`). المشروع مكتوب بـ HTML وCSS وJavaScript عادي، ويعمل كواجهة ثابتة مع دعم PWA.

> **حالة المشروع:** نموذج أولي قابل للتجربة، وليس نظاماً آمناً لإدارة بيانات العملاء أو اعتماد العضويات في الإنتاج. ملف `wallet.html` يحفظ بياناته في `localStorage` على الجهاز والمتصفح الحاليين، ولا يوجد خادم أو قاعدة بيانات أو تسجيل دخول للموظفين. رقم العضوية وQR في واجهة الضيوف يُنشآن في المتصفح، لذلك لا تستخدمهما كإثبات موثوق للهوية أو الاستحقاق.

## التشغيل

يمكن فتح `index.html` مباشرة للتجربة الأساسية، لكن خصائص Service Worker والكاميرا تحتاج إلى HTTPS أو localhost. لتشغيل خادم محلي باستخدام Python:

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000/`. لوحة الولاء موجودة في `http://localhost:8000/wallet.html`.

## الاختبارات

يتطلب تشغيل الاختبارات Node.js 18 أو أحدث، ولا يحتاج المشروع إلى تثبيت حزم خارجية:

```bash
npm test
```

الاختبارات تفحص صحة manifest، وجود الملفات المحلية التي يعتمد عليها التطبيق، وبعض الضمانات الأساسية لتكامل PWA والواجهة.

## مكونات المشروع

- `index.html` — تسجيل الضيف، بطاقة VIP، QR، نموذج الحجز وواجهة المنتجع.
- `wallet.html` — نموذج إدارة الولاء المحلي، البحث، النقاط، التصدير ومسح الرموز.
- `vip-enhancements.js` — تحسينات تفاعلية تُحمّل من Service Worker.
- `sw.js` و`manifest.json` — التخزين المؤقت وبيانات تثبيت التطبيق.
- `tests/smoke.test.js` — اختبارات تحقق سريعة دون اعتماديات خارجية.

## قبل الاستخدام الفعلي

1. أضف خادماً وقاعدة بيانات مشتركة، واجعل التحقق من الصلاحيات والعضوية على الخادم لا في المتصفح.
2. اجعل لكل موظف حساباً وصلاحيات محددة، وسجّل عمليات تعديل النقاط والحجوزات.
3. لا تضع رموز Telegram أو أي أسرار في JavaScript المرسل للمتصفح؛ مرّر الإشعارات عبر خادم.
4. راجع موافقة جمع البيانات وسياسة الخصوصية والاحتفاظ بأرقام الهواتف، واختبر إرسال Formspree الفعلي.
5. أضف اختبارات تكامل، نسخاً احتياطية ومراقبة للأخطاء قبل ربط النظام بعملاء حقيقيين.

## النشر

يمكن نشر الواجهة الثابتة عبر GitHub Pages أو أي استضافة HTTPS للملفات الثابتة. استخدام الاستضافة الثابتة لا يضيف قاعدة بيانات أو حماية للوحة `wallet.html`؛ لا تعتبر إخفاء الرابط وسيلة للتحكم بالوصول.
